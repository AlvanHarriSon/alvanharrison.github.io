03 Learning notes

Why does TCP need application framing?

TCP delivers an ordered stream of bytes. A call to send does not create a message boundary for recv. A length header tells the receiver how many bytes to gather before decoding a complete message or image.

What does a DNS lookup give me?

DNS maps a domain name to records such as IPv4 and IPv6 addresses. An address identifies an endpoint on a network; a port selects a service. The resolver may answer from its cache, so a new lookup does not always contact authoritative servers.

When is concurrent work parallel?

Concurrent tasks can make progress during overlapping time periods, even on one CPU core. Parallel execution means work actually runs at the same time on multiple execution resources.
