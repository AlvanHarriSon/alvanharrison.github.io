# Chenyu Zhao — Research & software

Static GitHub Pages website. Serve this directory over HTTP for local preview, or publish its contents to the personal Pages repository root. All site resources are local to this directory.

The page contains nine public repositories and three featured works. JavaScript adds a five-stage solar architecture explorer, project search and area filters, result announcements, mobile navigation, and current-section feedback. Native details elements expose more project information. Without JavaScript, all repositories, source links, project details and a written solar workflow remain available.

The architecture graphics describe the published workflows. They are schematic illustrations, not screenshots or measured model outputs. No coursework evidence, student ID or private environment information is included in the public page.

Fonts: Manrope and Instrument Serif, obtained from Google Fonts. Motion CSS/JavaScript is the unmodified taste skill motion layer; the original author files are retained in `assets/motion/`.
